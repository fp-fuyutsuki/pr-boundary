# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0]

### Added

- Deterministic pull-request scope evaluation from a trusted base policy.
- GitHub Action integration with exact-head commit status publication.
- Local CLI using the same pure evaluator.
- Protected-path, rename, changed-file completeness, and stale-state safeguards.
- Public specification, threat model, and contribution/security documentation.
